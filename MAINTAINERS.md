## Responsibilities

Maintainers should:
- Preserve the original exercise pages and media.
- Review correctness and Bootstrap markup.
- Check responsive behavior and accessibility.
- Ensure CDN versions and SRI metadata are accurate.
- Review asset licensing and contributions.
- Keep README, documentation and issue templates accurate.
- Avoid representing UI demonstrations as real authentication or enrollment.

## Maintainer access

Additional maintainers are granted repository access by the owner based on sustained contributions, reliable review, and understanding of the project's technical and educational scope.

## Reporting

Use public GitHub Issues for ordinary help and defects. Use private reporting as described in [SECURITY.md](SECURITY.md) for vulnerabilities.
