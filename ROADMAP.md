# Roadmap

This document tracks possible improvements to the static Bootstrap exercises. It does not promise delivery dates; priorities may change.

## Near-term quality improvements

- Replace generic document titles with meaningful per-page titles.
- Replace placeholder image alt text with accurate descriptions, or empty alt text for purely decorative imagery.
- Improve the navigation markup and responsive layout, including the large inline margin used to place the login button.
- Replace href="#" placeholders with meaningful destinations or clearly non-interactive examples.
- Add browser-based checks or a concise manual review checklist for responsive and keyboard behavior.

## Exercise improvements

- Add representative labels and captions to carousel images and confirm the timing and controls are usable.
- Make the login dialog explicitly present itself as a UI-only demo and avoid implying that credentials are submitted.
- Improve the course card action to demonstrate a real destination only if one is supplied.
- Document the source and reuse license of each media asset.

## Optional project structure

- Add an index page that links to the three exercises if a single entry point is useful.
- Add a consistent style guide and shared local assets only if the examples grow beyond these standalone pages.
- Consider bundling Bootstrap locally if offline use is a project requirement; otherwise keep the versioned CDN links with valid integrity metadata.
