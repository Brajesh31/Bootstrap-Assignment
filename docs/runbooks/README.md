# 🧰 Operational Runbooks

These runbooks describe repeatable actions for the static assignment. They do not assume an application server or deployment provider.

| Runbook | Purpose |
|---|---|
| [Local preview](local-preview.md) | Open and serve the task pages |
| [Asset verification](asset-verification.md) | Check relative media paths and image rights |
| [Static publishing](static-publishing.md) | Prepare and verify a static release |

Add provider-specific deployment and incident steps only after the actual host and its owner are known.
