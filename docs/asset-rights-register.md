## 1. Why this register exists

The repository contains local images used by the Bootstrap exercises and saved output screenshots. A file being present in Git does not prove that it is original, public domain, or licensed for redistribution.

The repository's MIT license covers the project code as stated in LICENSE. It does not automatically grant permission to reuse third-party photographs, logos, screenshots, or other media.

## 3. Required record for each future asset

Before adding or replacing an image, record:
- Filename: exact path committed to Git.
- Creator: photographer, designer, organization, or “unknown”.
- Source: original page or source repository.
- License: exact license name and version.
- Permission: license URL, written permission, or purchase record.
- Attribution: exact attribution text required by the license.
- Modifications: crop, resize, color edits, overlays, or other changes.
- Review date: date the rights were checked.

Keep proof of permission in an appropriate project record. Do not commit private purchase receipts, personal data, or confidential correspondence.

## 4. Adding an asset safely

1. Prefer original project artwork or assets with explicit reuse permissions.
2. Read the license terms, including commercial-use, modification, and attribution conditions.
3. Check whether the license is compatible with the intended distribution.
4. Use a descriptive filename instead of an opaque download identifier where practical.
5. Add meaningful alternative text when the image communicates information.
6. Update docs/assets.md, this register, and any page documentation that references the asset.
7. Optimize dimensions and file size without making text or meaningful details illegible.
8. Preserve the original asset when a replacement would otherwise destroy project history.

## 5. Removing or replacing an asset

If permission cannot be established and redistribution is not clearly allowed, do not assume the asset is safe to publish. Identify the affected page, obtain permission, replace it with a properly licensed alternative, or remove it through a reviewed change. Update screenshots and documentation only after the replacement has been verified.

## 6. Third-party dependencies

Bootstrap is loaded from jsDelivr. Its source and license are separate from the local media register. Consult the official [Bootstrap documentation](https://getbootstrap.com/docs/5.3/getting-started/introduction/) and [jsDelivr](https://www.jsdelivr.com/) when changing the dependency.
