# 📖 Glossary

| Term | Meaning |
|---|---|
| HTML | Markup language used to define page structure |
| CSS | Stylesheet language used to control presentation |
| Bootstrap | Front-end toolkit used for responsive layout and components |
| CDN | Content Delivery Network used to serve Bootstrap assets from jsDelivr |
| SRI | Subresource Integrity, browser verification of remote file hashes |
| `crossorigin` | HTML attribute controlling CORS behavior for selected resource requests |
| Card | Bootstrap content container used in Task 1 |
| Carousel | Bootstrap slideshow component used in Task 2 |
| Indicator | Carousel control that selects a slide by index |
| Dropdown | Expandable menu component used in Task 3 |
| Modal | Dialog overlay component used in Task 3 |
| Data API | Bootstrap feature that activates components through `data-bs-*` attributes |
| DOM | Document Object Model, browser representation of HTML |
| Relative path | A file path resolved relative to the current document URL |
| Alt text | Text alternative describing the content or purpose of an image |
| Viewport | The visible area of a web page in the browser |
| Responsive design | Layout approach that adapts to different screen sizes |
| Accessibility | Design and implementation practices that support users with different abilities |
| Static hosting | Serving HTML and asset files without an application server |
| API | Application Programming Interface; no project-owned HTTP API exists here |
| Persistence | Saving application data beyond a temporary browser interaction; not implemented in this project |
| Authentication | Verifying user identity; the modal in this project does not do this |
| Authorization | Determining what an authenticated user may access |
| ERD | Entity Relationship Diagram; not applicable to the current no-database project |
| CI | Continuous Integration, automated checks on changes |
| Mermaid | Text-based diagram syntax supported by GitHub Markdown |
