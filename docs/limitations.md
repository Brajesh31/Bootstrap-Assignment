# ⚠️ Current Limitations

This page describes constraints visible in the repository's actual HTML and asset structure.

## 1. Product functionality

- The project is an educational Bootstrap assignment, not a complete course platform.
- The Enroll Now link uses a placeholder `#` destination.
- Task 3 navigation links use placeholder destinations.
- The login modal is only a visual demonstration.
- The login form has no submission handler or backend.
- No authentication, authorization, session management, or password storage is implemented.
- No course enrollment, payment, progress tracking, or LMS capability exists.

## 2. Architecture

- There is no application server or API.
- There is no database or persistence layer.
- There is no package manifest, local build, bundler, or test runner.
- There is no custom application JavaScript module in the repository.
- Bootstrap is loaded from an external CDN.
- The repository root does not contain an index.html entry page.

## 3. Accessibility and UI quality

- Some images use placeholder alt text.
- Task 1 and Task 2 have generic page titles.
- Task 2 uses automatic carousel intervals without a visible pause control.
- Task 3 uses a large inline margin on the Login button that may affect narrow layouts.
- Some navigation links do not have meaningful destinations.
- Saved output images do not replace live browser testing.

## 4. Media licensing

Image provenance and reuse permissions are not recorded in the source files. The MIT license does not automatically grant reuse permission for third-party media.

## 5. Reassessment

Update this document only after a limitation has actually been fixed and verified. Do not remove a limitation merely because a future feature is planned.
